# Flashing instructions retired

**NO-GO.** See [the authoritative readiness record](flash-readiness.md).

The previous guide described an obsolete CH32V203 image and made unsupported restoration guarantees.
Its image size, first-flash procedure, and claimed Mac backup are withdrawn. Git history is not an operating procedure.

The current experimental target is CH32X035. Offline image checks do not prove execution on this keyboard.
The installer remains unread. The Mac dispatcher requires a working application, so it cannot establish independent recovery.
No custom image is authorized, and no firmware operation is part of M1.

Use [offline build checks](BUILD_AND_FLASH.md) or [stock iPhone characterization](../../../ios/ClicksInspector/SIGNING_AND_BASELINE.md).
